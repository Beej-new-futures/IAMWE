IW-08 — Daljit Kaur

The New Order

A window scheme about fashion's move into digital space. Screens are set inside built landscapes — a mound of pink rubble, a drift of paper, an arch cut from foam — so that digital work has somewhere physical to stand. The campaign's own lines run across the glass: fashion utopia is a wireframe for the future; meet the digital provocateurs.
